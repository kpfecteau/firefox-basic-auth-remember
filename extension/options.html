How host patterns work
example.com, localhost:8080
That exact host, and port if it isn’t the default.
*.example.com
Any subdomain, at any depth. * matches any characters. Add :port to limit it to one port.
/^dev\d+\.example\.com$/
A regular expression between slashes, case-insensitive. Without ^ and $ it matches anywhere in the host.

An exact match wins, then the longest matching wildcard, then the longest matching regular expression.
